# 仕様判断台帳

基準: [GameDesign v0.1](GameDesign.md)。この台帳は判断の所在を整理し、正式仕様を変更しない。初期状態には承認がなかったが、2026-10-18にDEC-01のPhase 1試作限定承認を受領した（下記参照）。

## 区分

- **確定**: §2。拠点は常に自動移動し、離れたプレイヤーを待たない。プレイヤーは独立して移動・離脱・追跡・再合流できる。移動拠点防衛を中心とする。
- **暫定**: §3のゲームループ案、§5.2の最小構成全項目（仮ステージ、8方向、一定速度、攻撃/敵各1種類、単純AI、拠点HP、距離クリア、HP0敗北、HUD）。実装の条件は企画担当に確認する。
- **未確定**: §8。AIが独断で正式採用しない。
- **対象外**: §5.3。複数ステージ、大量の武器/敵、複雑な成長、永続アップグレード、本格演出、オンライン、複雑な経路探索、大規模自動生成。

## DEC-02: Phase 2戦闘試作の承認（2026-10-24 JST）

承認者: **プロジェクトオーナー（企画担当）**。
[判断依頼v1](https://github.com/SyuLin1167/ProjectSurvivor/issues/8#issuecomment-6338641036) /
[企画回答・承認記録](https://github.com/SyuLin1167/ProjectSurvivor/issues/8#issuecomment-6368924005)。
適用は**Phase 2 / Issue #9〜#12の試作限定**。D1〜D7を推奨詳細込みで全承認。正式な製品仕様に昇格しない。

- D1: 射程内の最寄り有効敵1体へ周期的な自動即時命中。同距離は安定ID順、初回即発動、対象なしは準備維持。命中直前に生存・有効性・射程を再確認。1発1体1回、最小デバッグ表示のみ。
- D2: 基本敵1種類、キャラバン中心へ直線追跡。Pへの変更なし。押し戻しなし、拠点の移動を妨げない。対象消失で停止。撃破敵を攻撃対象/判定から除外。固定配置のみ。
- D3: 接触時初回即ダメージ、敵ごとの独立間隔。離脱でリセットせず非接触中は攻撃回数を蓄積しない。重複通知の多重ダメージ禁止、同フレーム撃破優先、大きな遅延時の連射禁止。通常の余り時間を保持しつつ1フレーム最大1発。

- D5/D6: PのHP/被弾/死亡は未採用・将来保留。攻撃/敵各1種類。手動スキル、複数武器/敵種、飛翔弾/範囲攻撃、属性/状態異常/クリティカル、ノックバック、回復/ドロップ、装備/経験値/レベル、護送依頼/パッシブ/報酬、恒久強化/保存、継続生成/ウェーブは対象外。
- D7: DEC-01の視点/8方向/相互通過/寸法/初期位置/マップ/終端15000u/中央追従/固定ズーム/方向距離/NEAR128uをPhase 2へ継続。P240u/s・キャラバン80u/sは固定。

初期値: P射程160u・攻撃10・間隔0.5秒、敵HP30・半径16u・速度120u/s・接触10・間隔1秒、キャラバンHP100。
調整委任はP射程128〜192u、P攻撃間隔0.4〜0.8秒、敵速度100〜140u/sのみ。変更前後・理由・検証方法と実測をIssue/PRへ記録。他の数値は固定。範囲外・方式・標的・HP0挙動の変更は事前承認。DEC-01のP/拠点速度調整委任をPhase 2へ延長しない。

#8の判断回答は完了。#9→#10/#11→#12の依存順と既存範囲を維持して着手承認。大規模設計変更・範囲外追加・PR自動マージは未承認。期待と実測を区別し、30/60/120fps相当、対象破棄、接触、再試行、未介入/防衛時残HPを検証する。

### 初期化・終了時の詳細

- P中心(512,2048)、拠点中心(768,2048)、拠点HP100、敵HP30、進行0、結果未決、攻撃タイマー初回発動可能、選択対象なしで開始する。#14は既存固定配置を維持し、#15導入後は承認された出現状態も新規プレイ単位で初期化する。
- 旧敵・Collider・イベント・対象参照・保留生成・UI登録を持ち越さず、Cameraの対象/位置/境界を新プレイに設定する。共有サービス全体の再生成は不要。再開始は有効な試作設定から生成し、比較試遊では同一設定を使う。プレイ中の設定即時反映は追加しない。
- 進行率は clamp((現在の拠点中心X−開始X)/(終端X−開始X),0,1)、残距離は max(終端X−現在X,0)。内部値で判定し、到達前に表示を100%へ丸め上げない。敗北時はその時点の進行を保持する。
- 結果は成功/敗北、終了時HP、進行率、操作のみ。生きたゲームオブジェクトの参照ではなく必要な値を引き渡す。終了後の移動・被害・生成を再開しない。正式演出や専用アセットは追加しない。
- **将来の製品版ではステージ開始時点のHP・装備・資源・強化状態を復元する再挑戦方式を企画方針として維持する。** 今回の初期値からの新規生成はその否定ではなく、保存・復元機能を今回実装する指示でもない。
- D7では30FPS未満でシミュレーションが実時間より遅く進むことをPhase 3限定で許容する。約60秒はシミュレーション時間の目安。明示的ポーズメニューは追加しない。CCDや全すり抜け防止の保証ではなく、#12の時間跳躍リスクを#18/#21へ引き継ぐ。時間供給への接続が大規模変更になる場合は再提案する。
